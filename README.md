# AI-Powered Real-Time-Speech-Translation-System

This project implements an AI-powered system for real-time speech translation designed for multilingual content processing. The system supports multiple input formats, automatically detects the source language, translates speech into multiple Indian languages, and provides both text and audio outputs.


## Features

- Supports audio input from microphone, uploaded media files, and YouTube links  
- Automatic detection of source language  
- Translation into multiple Indian languages  
- Speech-to-text transcription  
- Text-to-speech generation for translated content  
- Downloadable text and audio outputs  


## Tech Stack

### Backend
- Python  
- FastAPI  
- Uvicorn  
- Speech-to-Text (ASR)  
- Machine Translation  
- Text-to-Speech (TTS)  

### Frontend
- HTML  
- CSS  
- JavaScript  


## System Workflow

1. User provides an input source such as audio, video, or a URL  
2. Audio is extracted and processed by the backend  
3. Speech is converted into text  
4. The source language is automatically identified  
5. Text is translated into the selected target language  
6. Output is generated as translated text and optional speech audio
